A harder pull at chosen rows (BCA's dose, as published)

The idea
Multiply TD3+BC's pull toward the recorded command by up to 1.5 on the rows where BCA judges that the critic may be wrong.
What we tested (and the kill rule)
The main test's best-case caution check placed that pull by the critic's exact error. The pre-registered stop rule ended the test if this perfectly placed caution did not beat three controls by at least 3 points in some shifted situation.
What happened
It beat them by −1.9 to +1.1 points, so the test stopped before any BCA run (12 Oct).
Why
The pull acts only at recorded rows, where it says "drive like the recording"; the harm is made where the actor leaves the recording, in states the data never covered.
