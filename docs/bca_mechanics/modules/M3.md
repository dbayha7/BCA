## 1. What the module does, in plain words

BCA puts an error band around a **critic**, the learned estimate q of how much return a command earns from a state.
To size the band it needs to know how wrong the critic typically is. It measures that on the **held-out calibration
rows**: recorded steps (state s, command a, reward r, next state s') that the critic never trained on, about 800-850
rows per log after the study's removal. For each held-out row j the host computes two numbers (module M1):

- q_j, the critic's value at the recorded state and command, the smaller of the two critic heads;
- y_j, the **target**, the reward plus the discounted value the target critic gives the next step. The difference
  y_j − q_j is the **residual**, the critic's one-step error, in critic value units (returns).

Module M2 fits two more things while the critic trains: the **error-size network** η(s, a), a small network that
predicts, per row, how large the residual should be, and the **unit** u, a running scale of the residual in critic
value units. At a **refresh** the host freezes both (η_f, u_f).

Module M3 then turns each held-out residual into a **score**:

    sigma_j = max(eta_f(s_j, a_j), 1e-6) * u_f        the predicted error size, in critic value units
    rho_j   = |y_j - q_j| / sigma_j                    the actual error as a multiple of the predicted one

A score of 1 means the critic's error on that row was exactly as large as η_f·u_f predicted; a score of 2 means twice
as large. The scores are dimensionless, so rows with different predicted sizes can be compared on one scale. Module
M5 then finds the **threshold** R, the score below which 90% of held-out scores fall (with a 95% credible margin),
and module M6 turns it back into a band of half-width U = R·σ(s, a) at any (s, a). If η_f were a perfect size
predictor, R would come out at about 1; the recorded bands have R between 1.26 and 1.70, that is, the threshold has
to enlarge η_f·u_f by 26% to 70% to cover 90% of the held-out rows.

**Two numerical details that matter for exact reproduction.** The scale σ is computed in 32-bit floating point
(JAX's default) and then converted to 64-bit; the residual is a 32-bit number converted to 64-bit; the division is
done in 64-bit (`reference.py:164-165, 175`). The floor 1e-6 on η never binds in practice, because the network's
output is softplus(·) + 0.01 and so never below 0.01 (`calibration/network.py:28-31`); it exists so that σ can never
be zero.

**Where the same arithmetic is restated.** The weighting test recomputes the scores from a saved band with the same
formula (`experiments/shift_iw/learners_iw.py:540-552`, `_scores_from_state`) and *refuses to continue* unless the
unweighted threshold on them equals the band's stored threshold bit for bit (`learners_iw.py:564-572`, and at every
weighted refresh of a co-trained host, `936-938`). Stage 2 does the same (`outputs/shift/beyond-the-data/stage2/
code/band.py:307-314`, `bank_scores`, and `317-324`, `uniform_threshold_check`, whose result is written into every
band record as `uniform.threshold_recomputed`). The four-learner study restates it in
`experiments/shift_hosts/bca_core.py:387-391` on branch `claude/shift-hosts` and makes it a stop rule (S3).

**What this module does not do.** It takes no weights: module M4's weights enter only in M5, as how much each score
counts. The scores are computed once per refresh on the held-out rows, which come from the training log; they do
not depend on the test condition (recorded conditions or a shifted one) at all.

## 2. What "works as intended" means (checkable statements)

- **C1, the arithmetic.** On every held-out row the score equals |y − q| / (max(η_f, 1e-6)·u_f) with the scale in
  float32 then float64; every scale is positive and every score finite and non-negative; when any input is not
  finite (or u_f ≤ 0, or η_f ≤ 0), the refresh is declared invalid and the host keeps its previous threshold instead
  of scoring anything.
- **C2, exact reproduction.** From the saved critic, the saved η_f and u_f and the refresh key alone, in the pinned
  environment, the scores recompute bit for bit, and module M5 on them gives the stored R, plain quantile λ̂,
  credible quantile λ_hpd and effective size n_eff bit for bit (as stored, in float32). This is the statement the
  studies' own checks make (the weighting test's refusal gate, the four-learner stop rule S3, stage 2's and
  near-80's `threshold_recomputed`).
- **C3, the meaning on real data.** The share of held-out rows with score ≤ 1 is what η_f·u_f achieves on its own;
  the share with score ≤ R is what the band achieves on the rows it was calibrated on, and by M5's construction it
  must be at least 0.90 (a little above, because of the credible margin).
- **C4, independence of weights.** The score array is the same whatever weights M4 later supplies; weights of 1 give
  the unweighted threshold on it bit for bit.

## 4. Synthetic test: rows whose scores are known in advance

`M3_test.py` Part A builds 2,000 rows with a made-up error-size network (η uniform on [0.5, 2.0]), a unit u = 0.37
and residuals u·η·Z with Z standard normal, so the score of every row must equal |Z| and the true 90% quantile of the
scores is 1.645. It then calls the real functions (`positive_scale`, `freeze_reference`, `wbcp.calibrate`).

| Check | What is tested | Result |
|---|---|---|
| A1 | scores equal |Z| (known truth) | PASS: largest relative difference 5.7e-08 (float32 rounding); share ≤ 1.645 = 0.911 (truth 0.900); `freeze_reference` gives R = 1.648, plain quantile 1.594, credible 1.648 |
| A2 | an η that matches the 90% level gives R near 1 | PASS: residuals u·η·Z/1.645 → share ≤ 1 = 0.911, R = 1.002 |
| A3 | only the product u·η matters; a common factor on u and the residual cancels | PASS: (2u, η/2) bit for bit equal; (8u, 8·residual) bit for bit equal; factor 3 within 1.4e-07 |
| A4 | the 1e-6 floor on η | PASS: changes 0 of 2,000 rows when η ≥ 0.01; with η forced to 0 the scale is 1e-6·u = 3.7e-07 > 0 and the score stays finite |
| A5 | invalid inputs are refused, nothing is scored silently | PASS: a NaN residual, an infinite η, u = 0, and an R that overflows float32 each give valid = False and a reference that is not ready |
| A6 | determinism; the float32-then-float64 order | PASS: two calls give identical arrays; a float64-throughout scale changes all 2,000 scores by at most 5.7e-08, and the two thresholds agree in float32 (1.64807828 vs 1.64807835 in float64) |
| A7 | what M5 reads from the scores | PASS: λ̂ is the 1,800th smallest of 2,000 scores; after the monotone change x → x^1.5 both λ̂ and λ_hpd transform exactly, so the threshold depends on the scores only through their order and the values at two ranks |
| A8 | weights never enter M3 | PASS: weights of 1 on the same scores give the unweighted threshold bit for bit in float64 |

Reading A6 and A7 together: any reimplementation that reproduces the ranks reproduces λ̂ exactly, but to reproduce R
to the last bit one must copy the float32-then-float64 order, which is why the studies' checks compare in float32.

## 8. What to say to the advisor

1. The score step is one line of arithmetic with no tunable part: each held-out row's critic error divided by the
   error size the network predicted for it. Recomputed from the saved files in the pinned environment, it gives
   back every stored score and every stored threshold bit for bit on all 25 bands on record, and the studies
   checked the same thing themselves at every refresh (288 of 288 in the four-learner study).
2. What the scores show on real data is consistent across all 25 bands: the error-size network alone covers 76-82%
   of the held-out rows, so the threshold has to enlarge it by 26-70% (R = 1.26-1.70) to reach 90%; the band then
   covers 91.5-91.9% of the rows it was calibrated on.
3. Weights never touch this step. Importance weighting changes the penalty only because the scores are larger at
   high current (on 20 of 20 bands, 90% quantile 1.3-1.6 times higher in the high-current third) and the weights
   make those rows count more. That is the mechanism behind "IW raises the penalty even when training on recorded
   conditions": it is in M4/M5, not here.
4. The exceptional cases are three stage 2 bands (stalling world, gate critic, seeds 1-3) with single scores of
   29-34: rows where the critic's error was 20-40 times the median and the error-size network predicted its
   smallest error. They do not move the threshold, but they are the clearest sign that η's ordering of rows can be
   wrong exactly where it matters (module M2's caveat).
