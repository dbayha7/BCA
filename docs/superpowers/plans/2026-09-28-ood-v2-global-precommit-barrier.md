# V2 global precommit barrier component

Implement a separate outcome-blind integration component without changing any
closed source. The real stream collision remains held awaiting explicit direction.
No real keys, candidate pools, model queries, physics or resource writers run here.

1. Read an externally pinned index containing all256 nominal capture rows for one
   declared pair, the saved complete key table/binding, candidate banks and warning
   scores. Verify exact bytes, capture identity, missing-state reasons, bank/key/
   snapshot bindings,14 fixed slots and warning coverage before writing one seal.
   The barrier is global across the pair's256 rows, not across all20 future pairs.
2. Keep the independent semantic review separate. Its externally pinned receipt
   must bind the exact seal and execution declaration and explicitly cover streams,
   native state/candidate/warning semantics, runtime, resources and supervision.
   A producer seal never confers scientific or execution acceptance itself.
3. Add a guarded, single-process panel dispatcher. Bind every host then BCA panel
   to that seal; archive a unique start before invoking an injected callback and
   an exact completion afterward. Include missing rows without calling outcomes.
   Refuse reuse/reentry/changed inputs or ownership; any failure poisons the phase,
   preserving an unresolved start. This is not recovery or automatic retry.
4. Test synthetic raw stores/key tables/captures/banks/warnings and callback
   counters, including the256-row barrier, missing rows, late changes, rejected
   acceptance, pending starts and durability failures. Do not run prior suites.
5. Review and document what is structural versus independently unverified;
   preserve actual test exits, exact source hashes and all previous failures.
   Publish only owned code/small evidence after frozen-file integrity checks.

The actual archive/native driver callback, final-device durability, reviewer
provenance, checkpoint/runtime binding and supervisor still require integration
and independent acceptance. Synthetic gate receipts cannot authorize real work.
