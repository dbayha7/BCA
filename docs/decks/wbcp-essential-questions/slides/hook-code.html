The hook: where the dose enters TD3+BC's actor loss

algorithms/td3_bc.py · _actor_loss_fn, lines 128–139

def _actor_loss_fn(params, critic_params):
    pi = actor_apply_fn(params, batch.obs)
    q = critic_apply_fn(critic_params, batch.obs, pi)[..., 0]
    lmbda = args.alpha / jax.lax.stop_gradient(jnp.abs(q).mean())
    if bc_multiplier is None:
        bc = jnp.square(pi - batch.action).mean()
    else:
        bc = (
            jax.lax.stop_gradient(bc_multiplier)
            * jnp.square(pi - batch.action).mean(axis=-1)
        ).mean()
    return (-lmbda * q.mean() + bc, (q.mean(), lmbda, bc))

The actor reads head 1 only: [..., 0]. Its weight λ uses TD3+BC's own α = 2.5, not the calibration α.

BCA passes its dose as bc_multiplier. It scales each row's BC error, detached by stop_gradient. The Q term is untouched.

“Today's hook” in the results means exactly this one detached multiplier.
