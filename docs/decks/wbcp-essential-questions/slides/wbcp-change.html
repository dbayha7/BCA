Question 1 · Is our WBCP code right?

Did the rewrite fix a real defect?

The archived radius was the larger of a finite-rank conformal radius and a Bayesian-bootstrap quantile, with no test atom (tag bca-bayesmax-archive).

It was overconfident: its nominal 95% credibility was really 88.8% (n = 50), 94.3% (n = 200) and 93.9% (n = 1,000).

Adding only the test atom closed the gap. “Exchangeable” in the chart means no shift.

Also changed: the fitted importance weights and ESS gate were removed and an n ≥ 36 gate added. The dose formulas did not change.
