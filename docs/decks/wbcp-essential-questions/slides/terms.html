Part 1 · The models

Words and symbols used throughout

Score = |y − q| / σ(s, a). y is the host's TD target, q = min(Q1, Q2) of the critic's two heads (IQL: target heads), σ is BCA's learned scale.

Threshold λ: the cut-off a rule certifies. Miscoverage of λ: the share of test rows whose score exceeds it. Target α = 0.1.

Frozen pool: one dataset's held-out rows, scored once by a critic trained 100k updates (one seed). Any λ's miscoverage on it is exact.

Bank: n rows drawn from the pool. Independent-row bank: n rows drawn iid. Whole-episode bank: every row of a few episodes (BCA's original rule). Thinned bank: K spaced rows from each of many episodes (BCA today).

Shift (tilt): reweight the pool's rows by exp(γ z), with z a feature of (s, a) only. γ = 0 is no shift.

ρ: within-episode correlation of misses. K: rows per episode. Logged action: the dataset's action; every D4RL check uses it, never the actor's own action π(s).

Datasets: hopper-medium, halfcheetah-medium-expert, walker2d-medium-replay, maze2d-large, pen-expert, pen-cloned, pen-human. Hopper is the test bed for questions 2–3 (n = 1,103; others 1,024; IQL configs 8,192).

Not in any result yet: the training loop itself, where the bank is rescored at every refresh.

The pipeline figure writes the deployed threshold as R; everywhere else it is λ.
