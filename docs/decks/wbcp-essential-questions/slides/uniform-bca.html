At each refresh BCA scores the held-out bank with the frozen scale σ = u·max(η, 10⁻⁶) and calls calibrate with no weights.

No weights means uniform weights and test mass 1 (wbcp.py lines 66–69): exactly BQ‑CP. The notebooks label it “Uniform BCA”.

Shift-blind: it certifies the behaviour data's distribution. The deployed value is result.threshold = max(λ̂, λ_hpd).
