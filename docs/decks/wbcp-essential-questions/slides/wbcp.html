Lou & Luo (arXiv:2604.06464v3). Row i gets w_i = p_test(x_i) / p_cal(x_i), x = (state, action). The test atom gets w̄ = E_test[w] (the paper's Eq. 6).

Same crossing rule with masses w_i·E_i, so it corrects covariate shift: (s, a) moves, the error given (s, a) does not.

Uniform weights recover BQ‑CP exactly. BCA does not deploy weights.

Price: when a few rows carry most of the weight (Kish n_eff = (Σw)²/Σw² summarizes it), crossings spread and λ widens. If the test atom alone exceeds α in more than 5% of draws, the rule abstains.
