def crossings(sorted_scores, sorted_weights, test_mass, exponentials, alpha):
# …
    mass = exponentials[:, :-1] * sorted_weights
    total = mass.sum(axis=1) + exponentials[:, -1] * test_mass
    covered = np.cumsum(mass, axis=1) >= (1.0 - alpha) * total[:, None]
    return np.where(covered.any(axis=1), sorted_scores[covered.argmax(axis=1)], np.inf)

Snell & Griffiths (2025). Each of M = 1,000 draws gives the n scores random Exp(1) masses (Dirichlet once normalized), plus one test atom that is never covered.

A draw's crossing: the first score where the covered mass reaches 1 − α of the total, test atom included. λ_hpd is the 950th smallest crossing.

Deployed λ = max(λ̂, λ_hpd), where λ̂ is the smallest score whose empirical coverage reaches 1 − α.
