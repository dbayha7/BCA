Part 1 · The models

Two ways a bank holds less than its n

Uneven weights · “n_eff (weights)”

Kish n_eff = (Σw)² / Σw². A few heavy rows dominate each posterior draw, so λ widens. Under the density tilt at γ = 1 on hopper, 1,103 rows count as 391.

Correlated rows · “n/D (dependence)”

If misses in one episode have correlation ρ and the bank takes K rows per episode, the design effect D ≈ 1 + (K − 1)ρ makes the bank count as n/D rows. The posterior assumes D = 1, so P(fail) ≈ 1 − Φ(1.645/√D) instead of 5%.

def predicted_failure(design_effect, beta):
    return float(stats.norm.sf(stats.norm.isf(1 - beta) / math.sqrt(design_effect)))
