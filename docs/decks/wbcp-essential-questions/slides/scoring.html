def summarize_arm(thresholds, risk, alpha):
    trials = thresholds.size
    certified = np.isfinite(thresholds)
    failures = int(np.sum(risk > alpha))
# …
    return dict(
        fail=failures / trials, ci=[float(low), float(high)], failures=failures, trials=trials,
# …
        risk=float(np.mean(risk)), # abstentions count as risk 0
# …
        abstain=1.0 - float(np.mean(certified)),
# …
    )

Fail: a bank whose threshold misses more than α = 10% of test rows. Valid: at most 5% of banks fail (1 − β, β = 0.95).

Banks per cell: 2,000 (D4RL benchmark), 4,000 (dependence, host matrix), 10,000 (paper reproductions), 1,000 (critic alignment).

Abstain (λ = ∞) counts as a pass here; the paper reproductions count certified trials only, so the two differ where abstention is common.
