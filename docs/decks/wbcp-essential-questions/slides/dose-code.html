How the calibrated width becomes a dose

calibration/dose.py · frozen_level_dose lines 74–76, level_critic_dose lines 53–60 (excerpt)

threshold, unit = reference.threshold, reference.residual_scale
scale = jnp.maximum(predictions, 1e-06) * unit
width = threshold * scale
# …
safe_u, safe_c = (jnp.where(support, widths, 0.0), jnp.where(valid_unit, unit, 1.0))
# …
ratio = u_norm / (u_norm + c_norm)
dose = 1.0 + jnp.where(valid_blend, blend, 0.0) * ratio

Width U = λ × σ(s, a) at each logged row; u = the residual unit. In the code, safe_u is U and safe_c is u (rescaled as u_norm, c_norm).

Dose m = 1 + 0.5 · U/(U + u) (blend 0.5), i.e. m = 1 + 0.5·λη/(1 + λη). It runs from 1, the host's own weight, toward 1.5, which no finite width reaches.

Edge cases: an abstaining threshold (λ = ∞) or a not-yet-ready reference gives m = 1, the native weight.

σ is learned online: η takes one Adam step per batch on a coverage loss; u tracks the residual spread. Frozen-critic studies reuse that fit (critic alignment) or refit σ (signal study step 2).
