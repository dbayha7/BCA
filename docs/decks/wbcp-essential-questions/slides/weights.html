Exact (“oracle”): we impose the shift, mass a_i = exp(γ z_i), so the true ratio w* = a/mean(a) is known. Tilts: policy z = −‖a − π(s)‖, state z = ‖s‖, density z = log distance to the 10th neighbour (sparse rows gain mass).

Estimated: a logistic classifier separates uniform pool draws from tilted draws, both independent of the scored bank. It sees the tilt's own feature, so it is well specified: a best case. Fit on 1,000 + 1,000 rows.
