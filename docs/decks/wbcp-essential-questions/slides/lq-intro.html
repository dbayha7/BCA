Part 1 · The models · the test environment

A known-MDP harness where the true error is known

The MDP: linear dynamics s′ = As + Ba + ε, quadratic reward, linear actor a = −K_π s. The true Q^π and the true value J are exact.

Behaviour data: “good” is the LQR-optimal gain plus noise (J = −2.30); “poor” has no feedback (J = −4.43).

Critic heads = Q^π + a built-in error. q1_optimistic: Q1 optimistic away from the data, Q2 exact. q2_optimistic: the reverse. shared_bias: both heads share a Bellman-consistent bias. independent_errors: separate random errors. Controls: clean, noisy reward.

A cell = case × error size κ × how far the start policy sits from the behaviour policy.

Doses compared: BCA's; a constant dose with the same mean; BCA's doses shuffled across rows; an oracle built from the true Q1 error.
