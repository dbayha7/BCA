Part 3 · Host algorithm first, then each BCA component from the source

What BCA computes, line by line

Every equation below was read from the pinned source in this checkout (the full audit with line numbers is docs/thrusterchain/site/BCA_AUDIT.md). The host is unchanged Unifloral TD3+BC. Original BCA adds an auxiliary model that predicts how large the critic's own training residual tends to be, calibrates a threshold for it with a Bayesian bootstrap, and subtracts the resulting width from the critic's value inside the actor's objective. It touches nothing else.

The host: Unifloral TD3+BC, exactly as run

Identity. Unifloral revision f2dc1278eae18ed3e22c92255119c54885414d17, file algorithms/td3_bc.py with sha256 6f5ab6f9…, loaded as a hash-checked slice of eight definitions and nothing else. Settings for ThrusterChain: discount 0.98, batch 256, Adam at 3·10⁻⁴, two critic updates per actor update, target smoothing noise 0.2 clipped at 0.5, Polyak step 0.005, BC weight α = 2.5.

Networks. Two independent critic heads, each: normalized observation and action → 256 → 256 → 1 with ReLU. One deterministic actor: normalized observation → 256 → 256 → 4 → tanh. Normalization is (obs − mean)/(std + 0.001) with the training set's statistics, inside every network.

One outer step of the host

  1. Sample one minibatch of 256 logged transitions (s, a, r, s', done).
  2. Twice on the same minibatch: smooth the target action a' = clip(π_target(s') + clip(N(0, 0.2²), ±0.5), ±1); form y = r + 0.98·(1 − done)·min(Q1_target, Q2_target)(s', a'); take one Adam step on mean over batch and over both heads of (Q_h(s, a) − y)².
  3. Once: the actor's action a_π = π(s); the first head's value q = Q1(s, a_π); the detached normalizer λ = 2.5 / (mean|q| + 10⁻⁷); the behavior-cloning term BC = mean over the 4 coordinates of (a_π − a)²; one Adam step on L_actor = −λ·mean(q) + mean(BC).
  4. Polyak-average the actor target and the critic targets with step 0.005.

Source: td3_bc.py lines 174–279 (train step), 65–114 (networks), 38–46 (settings). The actor sees head 1 only; the target uses the minimum of the two heads. done is 1 on the hundredth transition, so nothing is bootstrapped past the horizon.

The BCA addition in one picture

Five components, in the order data flow. The first four run on every critic update or at a refresh; only the fifth changes what the actor learns.

1 · Residual and unit

In: minibatch, current and target critics.
Out: residual y − q per row; a running scale u.
Purpose: define the error the width is about.

2 · Local scale network η(s, a)

In: observation, action.
Out: a positive number per row.
Purpose: predict where residuals are large, in units of u.

3 · Calibration threshold R

In: 128 held-out rows, frozen η and u.
Out: one number R, or a refusal.
Purpose: scale η so the band covers 90% of held-out residuals with 95% posterior credibility.

4 · Width U and the frozen reference

In: R, u, η frozen at the last refresh; a live action.
Out: U(s, a) = R·u·max(η(s, a), 10⁻⁶).
Purpose: the quantity the actor subtracts.

5 · Actor-side penalty

In: Q1, U, κ.
Out: the actor objective with Q1 − κU.
Purpose: steer the actor away from actions whose value is uncertain. Critic loss and target are untouched.

Component 1: the residual and its unit

y = stop_gradient( r + (1 − done)·0.98·min_h Q_h,target(s', a') ), a' = clip(π_target(s') + clipped noise) q = stop_gradient( min_h Q_h(s, a_logged) ) current critic, twin minimum, LOGGED action residual = y − q u ← 0.99·u + 0.01·max( std_batch(y − q), 10⁻⁶ ) starts at 1.0; updated after every accepted fit

This is the host's own temporal-difference error, measured at the logged action with the twin minimum on both sides and one fresh smoothing draw per row. Three things it is not: it is not the error of Q1 against the simulator reference; it carries no sign once the absolute value is taken in the next steps; and it is measured at logged actions, while the penalty will be read at the actor's actions. The pipeline validation makes the gap concrete with a fixture in which Q1 = 10, Q2 = 0, reward 0 and target 0: the twin-min residual is 0, so the width is 0, while Q1 is wrong by 10.

Source: uncertainty_source/historical/td3_bc_bca.py lines 146–156 (target), 170–174 (q), 196–198 (unit); pipeline check 17.

Component 2: the local scale network and its fit

η(s, a) is a small network: normalized observation and action → 64 → 64 → 1 with ReLU, then η = softplus(·) + 0.01, so it is always above 0.01. It is fitted once per critic update on the same 256-row minibatch, after that critic update, with Adam at 10⁻³.

  1. Compute y and q as in component 1 (both detached).
  2. Draw Bayesian-bootstrap weights: E_i ~ Exp(1), p_i = E_i / Σ_j E_j, one draw per fit.
  3. Soft two-sided coverage per row: c_i = σ(20·(y_i/u − (q_i/u − η_i))) · σ(20·((q_i/u + η_i) − y_i/u)).
  4. Loss: (Σ_i p_i c_i − 0.9)² + 0.005·Σ_i p_i η_i², so the band aims at 90% coverage and is otherwise as narrow as possible.
  5. One Adam step; then the unit update of component 1. Accept only if every input, the loss, the gradient, η > 0 and u > 0 are finite; otherwise keep the previous state.

Source: calibration/network.py lines 8–46; td3_bc_bca.py lines 159–231; training.py (order: microstep, then fit on the same batch). The checkpoint made 20,000 such fits.

Component 3: the calibration threshold, a Bayesian bootstrap over 128 held-out rows

At critic updates 10,000, 15,000 and 20,000 (and at 21,000 in the continuation pilot) the scale network and the unit are frozen and a threshold is selected on the held-out bank: one logged row from each of 128 episodes that never train.

  1. For each held-out row: a fresh target y_j, the twin-min q_j, the frozen η_j; score S_j = |y_j − q_j| / (max(η_j, 10⁻⁶)·u), in float64.
  2. λ̂ = the smallest sorted score at which the cumulative count reaches 90% of the 128 (an exact-rational empirical quantile).
  3. For each of 1,000 draws: weights E_1 … E_128 plus one extra E_129 for the unseen test point, all Exp(1); the draw's crossing is the smallest score at which the cumulative weighted mass reaches 90% of the total including the test atom, or +∞ if the test atom alone exceeds 10%.
  4. λ_hpd = the 950th smallest crossing (95% credibility).
  5. R = max(λ̂, λ_hpd); n_eff = 128 with unit weights. Store R, λ̂, λ_hpd, u and the frozen η parameters as the reference, with ready = true.

Meanings: α = 0.1 is the target miscoverage, β = 0.95 the posterior credibility, and the 1,000 are draws over the threshold, each a reweighting of the same 128 scores. They are not critic heads, not model samples and not samples of Q. With unit weights this is the exchangeable case of weighted Bayesian conformal prediction (BQ-CP). The code accepts importance weights, but no caller in the current work passes any, so importance-weighted BCA remains a proposal. If fewer than 950 draws cross, R is +∞ and the refresh is refused; the trainers never commit a non-finite reference.

What the threshold promises. With posterior probability 0.95, at least 90% of exchangeable held-out one-step twin-min residuals at logged actions fall within R·u·η. It promises nothing about Q1's error against the simulator, about the actor's own actions (which are not logged actions), about starts outside the recorded law, or about return.

Source: calibration/reference.py lines 17–20, 124–194; calibration/wbcp.py lines 43–117; td3_bc_bca.py lines 234–280. Pipeline check 4 on a test snapshot recorded R = 4.8746, λ̂ = 4.5344, λ_hpd = 4.8746; the trained checkpoint's own values at update 20,000 live in the runtime assets and are not shown here.

Component 4: the width and the frozen reference

U(s, a) = R · u · max( η_frozen(s, a), 10⁻⁶ ) parameters R, u, η frozen at the last refresh; the action a stays live not ready (before the first refresh): U = 0 and "usable" = false unusable or non-finite in the continuation adapter: the step is refused, never trained with a silent zero

The actor always consumes the reference frozen at the last refresh, not the live scale network, so a refresh changes what the next actor step sees. Because the parameters are frozen but the action is not, dU/da reaches the actor through η: this is what makes the penalty action-specific. Pipeline check 15 measured the gradient through the frozen reference at exactly 0 and the same gradient with the freeze removed at 1.76.

Source: historical/direct_extension.py lines 47–70; continuation.py lines 72–77 and 247–249.

Component 5: the actor objective with the penalty

L_actor,BCA = −λ · mean_B( Q1(s, a_π) − κ · U(s, a_π) ) + mean_B(BC) = L_actor,host + λ · κ · mean_B U(s, a_π) λ computed from the UNPENALIZED Q1 and detached; κ = 0 reproduces the host bit for bit (check 7) critic loss, target y, data, BC term: unchanged

Only the actor's gradient changes. The critic parameters are constants inside the actor loss, but dQ1/da and dη/da are live, so the actor is pushed toward actions with higher value and smaller width. Checks 8 to 14 confirm the identity grad(BCA) = grad(host) + λκ·grad(mean U) for κ in {0, 0.03, 0.1, 0.3, 1, 3, 10}.

What calibration does not buy

  • A calibrated band on the training residual is not a bound on Q1's true error at the actor's action. The operator audit measured how far apart they are.
  • An absolute band has no sign. It cannot say whether an action is over- or underestimated; it can only make every value smaller.
  • A width that is constant across a state's actions has zero action gradient and cannot move the actor or change a ranking. Only the contrast between actions matters for decisions.
  • Exchangeability holds for held-out logged rows under the recorded start law. The actor's own actions, and any shifted start law, are outside that guarantee.
