# Evaluation-only rerun review

The continuation's evaluation stopped when a Windows-mounted progress file could not be replaced. This package retries transient permission errors, throttles progress writes, and tolerates an exhausted retry only for progress; a failed result, bank, report, or receipt write remains fatal. The scientific evaluator and protocol are unchanged from the sealed continuation.

The gate checks both state banks, authenticates each previously recorded context, then checks either identical bytes or the approved strict near-exact numerical rule. It expects 143 prior contexts and one specified new context. A defensive correction authenticates the recorded file even when the new bytes match its descriptor; tests cover tampering in both exact and near-exact paths. Launcher tests use synthetic workers, not training or evaluation.

The checks and their limits are recorded in `RERUN_CHECKS.json`. The real GPU entry and reproduction are not verified by preparation tests. The previous 143 results were not inspected for outcomes during this preparation. This package permits one bounded evaluation attempt and no training, automatic retry, or third evaluation attempt. The approved protocol explicitly reserves the launch for the user's own terminal.
