# Common-action and common-continuation frozen diagnostic

This single exploratory diagnostic uses the six saved final 20k hole-condition checkpoints (three paired seeds, native and original BCA) and their v3 auxiliary scores. No actor, critic, target or auxiliary optimizer update is permitted. No user-authorized training study is included.

## Question and fixed scores

For the same physical state and identical candidate actions, contrast each critic's raw Q1, symmetric Q1 BCA, guarded/unguarded compatibility hybrid, and width-matched hybrid. Apply each fixed score under both saved-actor continuations. The own-continuation diagonal is the checkpoint's frozen Q-pi action diagnostic. The off-diagonal is intentionally a cross-policy reference, not that critic's own-policy accuracy. Difference across continuations for the same critic and actions implicates the reference/continuation; difference across critics for the same reference and actions implicates score-side contrasts. Neither comparison identifies the causal effect of BCA training.

Restore the original v3 model artifacts and v3 coefficients. Reconstruct the three v3 residual references per checkpoint using the exact archived 64 calibration rows and recorded v3 JAX key; require exact numerical equality with the saved v3 Q1, twin and signed thresholds and saved training-state digests. Count 18 deterministic reconstruction refresh calls, not newly collected calibration or optimizer fitting. The compatibility reference is also deterministically reconstructed from the original retained training episodes and probes, including its earlier cross-validation calculations; its fingerprint, selected bandwidth and radius must exactly match v3. Match coefficients are reused verbatim; no coefficient, bandwidth, radius, actor, critic or auxiliary parameter is newly selected or tuned in this diagnostic. Reusing v3 development calibration does not provide fresh calibration or shifted-policy coverage. Include raw, Q1 symmetric, twin symmetric, signed Bayesian/split, signed mean/gradient matched, revised compatibility, signed+guarded compatibility, symmetric+guarded and symmetric+unguarded compatibility and symmetric width matched to the guarded hybrid's gradient. Scaling a signed bound has no original calibration guarantee.

## State and candidate construction

For each context 16 new shared random-prefix states are sampled, four each at t=0,25,50,75. For each seed/context and each actor, additionally create 8 states reached by that frozen actor from independent new starts, two at each time. Pool all three sources so both critics and continuations query the same 32 states per seed/context, eight at each time. Random-prefix and the two actor-visited strata are reported separately; the latter are not whole-policy returns. Reset seeds, prefix random streams and all source identities are collision-audited against original and earlier development/evaluation seeds; no protected logged transition data are read.

Construct the same 15-action bank for both critics/continuations at each state: native actor action, BCA actor action, eight +/-0.2 coordinate perturbations about their midpoint (all bounded and clipped), and five original fixed vectors. Keep duplicate slots. Candidate actions depend only on frozen actors and states, not critic score or any Q-pi label. Score and persist every state/action/score bank before requesting any Q-pi. On every candidate query each of the two saved actors as a continuation, with gamma .98 and finite horizon 100, no terminal bootstrap. This computes 5,760 own- and cross-policy references, not Q-star or policy-return estimates.

## Metrics and bounded work

Each seed, context, state source, critic and continuation reports mean regret to the best of the same 15 candidates; gains and harmed switches for raw->symmetric, symmetric->guarded, guarded->unguarded; signed Q error and MAE on identical rows; and guard-on/off strata. Changed actions with Q-pi gain >0.1 or <-0.1 are improved/harmed; remaining changed choices are near-tied. Primary mechanistic contrast is guarded hybrid versus symmetric on own-continuation actor-visited states; random-prefix and off-diagonal cross-policy are separate diagnostics. A source-specific seed cell with fewer than four non-tied changed states is inconclusive for decision benefit; regardless, report all values. For a seed qualifying own-continuation cell require average selected Q-pi gain >=.05 versus symmetric and harms <= improvements. A context passes only if >=2/3 seeds qualify in each native and BCA own-policy group. If too few eligible cells to establish that, mark inconclusive; otherwise absent qualifying groups is failure. These are engineering screens, not statistical significance or a learned-policy efficacy test.

Fixed maximum: 1,200 random-prefix + 3,600 actor-prefix + 104 parity + 360,000 forced-continuation simulator transitions = 364,904. Exactly 129 reset calls (32 random + 96 actor-prefix + one parity), 5,760 references, and zero optimizer updates. Actors run only for frozen inference. 18 replayed reconstruction refresh calls use already consumed v3 calibration episodes; no new calibration episode or simulator fitting. Two-hour cap and no automatic retry. Immutable source seal; fail closed and retain partial accounting without claiming completion. Three paired training seeds and one dataset remain the replication units; states, actions and same starts are dependent. No policy-return or safety guarantee follows.
