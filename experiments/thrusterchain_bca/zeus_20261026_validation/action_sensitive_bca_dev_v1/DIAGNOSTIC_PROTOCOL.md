# Bounded Q1 and action-compatibility diagnostic, version 1

This development-only protocol is fixed before running this diagnostic. The user authorized implementing the two modifications and a bounded diagnostic on saved checkpoints, but not a full training study. No actor, critic or target optimizer update, policy rollout, simulator transition or environment feedback is authorized. Existing evaluation outcomes and calibration episodes have been seen or used previously; this is not independent confirmation or a new conformal guarantee.

## Scope and question

Use exactly the six saved final 20k **hole-condition** checkpoints: seeds 0, 1 and 2 for each of the native and original BCA branches. In both previously evaluated contexts (ordinary and strong current), use the 32 saved state families and all six saved candidate actions, including the actor's own action. Authenticate checkpoints, reference arrays, report and banks against the completed evaluation's pinned evidence. The saved Qπ values follow each checkpoint's own deterministic actor after the candidate action; they are not Q-star, smoothed TD targets or a common-policy reference. All comparisons below keep the critic, action, state and Qπ fixed.

Questions: (1) does aligning the one-step auxiliary residual to online Q1 improve absolute score error and reduce overestimation without creating unacceptable underestimation? (2) does a training-only action compatibility term create meaningful *within-state* penalty differences and improve or harm forced-bank choices? (3) do these results exceed a compatibility-only and strength-matched Q1-width control? Neither this diagnostic nor improved bank choices establishes a learned-policy return gain.

## Inputs and fitting

Only the existing 768 retained training episodes of the hole data condition are used for auxiliary fitting and action-compatibility reference. Preserve intact stored transitions, original action scale and finite-horizon masks. The existing 128 eligible calibration rows are one per distinct calibration episode. Sort by episode ID and alternate into 64 calibration rows and 64 descriptive check rows; these episodes were previously consumed and are not an independent confirmation set. No held-out Qπ, evaluation actions or evaluation values enter fitting, calibration, bandwidth, coefficient matching or model selection.

For each checkpoint, initialize **two** fresh auxiliary scale models and residual units from scratch using identical initial seeds: one fitted/calibrated on the actor-used online Q1 residual, the other on the original online twin-min residual. Bind both to the same frozen native actor and unchanged smoothed twin-min target; fit each for exactly 2,000 auxiliary optimizer updates, batch size 256, using identical replacement minibatches and keys drawn from retained training transitions. No actor/critic/target update. Fit and calibrate the same residual in each pipeline; do not rescore a twin-min-fitted model as Q1-aligned. Calibrate each on the same 64 fixed calibration episodes with the same key, 1,000 Bayesian-bootstrap draws, α=0.1 and credibility 0.95, with finite valid thresholds required. Evaluate residual calibration separately on the other 64 rows, then score saved banks. The fresh twin-min comparison isolates head alignment from changed fit duration and data; the saved historical width remains a descriptive third reference. The target is a smoothed one-step bootstrap proxy and need not measure signed or absolute true-Q error. This split is development-only and remains potentially dependent on checkpoint training history.

Compatibility uses 64 nearest retained training states within each ten-step time bin and a four-dimensional Gaussian action kernel. Observation normalization and action bandwidth come only from training folds. On the 768 retained logged training probe observations, evaluate actor-proposed actions with five-fold episode cross-fitting: reference neighbors and reference normalization/bandwidth exclude the query's entire fold. At external cached evaluation anchors use all retained training episodes. Neighbor selection, normalization, bandwidth and reference actions are frozen with respect to the live proposed action. Compatibility is a relative density heuristic, not a proof of local support; all four action coordinates count.

For each checkpoint calculate an η from the same 768 cross-fitted training-probe states and frozen 20k actor proposals so that the RMS action-gradient norm of ηD is 25% of the RMS action-gradient norm of raw Q1. This is an exploratory coefficient computed at the *20k* checkpoint, not the previously proposed 10k-fork training coefficient. Compute a multiplier for Q1-aligned width alone whose RMS action-gradient norm matches that of the combined `3U_Q1 + ηD`, on the same probes. Freeze both coefficients before accessing cached Qπ. In any checkpoint if the Q or D gradient is nonfinite or ≤1e−6, η is nonpositive or >30, or the aligned width gradient is ≤1e−6 or its matched multiplier >30, fail that checkpoint closed; do not clip or substitute. A failed threshold or numerical check is a result of this bounded attempt, not permission to adjust it after reading outcomes.

## Prespecified scores and measurements

Compute and compare exactly these score variants on identical saved candidates:

1. Raw Q1.
2. Original calibrated score `Q1 - 3 U_original` (saved reference width).
3. Fresh matched twin-min `Q1 - 3 U_twin_fresh`.
4. Fresh Q1-aligned `Q1 - 3 U_Q1`.
5. Compatibility-only `Q1 - ηD`.
6. Combined `Q1 - 3 U_Q1 - ηD`.
7. Strength-matched Q1-aligned width-only `Q1 - κ_matched U_Q1`.

For every seed, checkpoint arm and context, report all actions and the fixed high-load band separately; signed error `score - Qπ`, MAE, RMSE, tolerance ±0.1 over/under/near counts, improved/worsened/near-tied absolute errors, sign crossings, bank regret, and choice changes with improved/harmed/near-tied outcomes. Report the Q1 top-two margin against penalty contrast between those same actions, and candidate-wide penalty ranges. Report all 32 anchor families, and 21 ordinary / 32 strong-current high-load anchors if these match cached bank identities. State explicitly that the six action rows per family are dependent. Calculate cached visited-state error on the existing 128 policy-visited rows where available, using exact cached suffix references; no new simulated data.

Record fitted/heldout residual scores, thresholds, calibration sizes, optimizer steps, raw sampler seed and RNG, probe cross-fitting data identities, matched coefficients, gradient norms and finite-difference consistency, checkpoint and cached reference hashes, device/precision, elapsed time, and all failures. Fail closed on incompatible cached CPU versus saved GPU action/Q1 beyond `|new−old| ≤ 1e−5(1+|old|)`, malformed or changed pins, nonfinite values, calibration rejection, wrong model/counter identity or incorrect rows. Save explicit measured maxima, not a bitwise-equivalence claim. Freeze state and count both before/after all reads; no policy-changing updates.

## Work limits and decision

Exactly six checkpoints, 12 contexts, 24,000 auxiliary optimizer updates, 12 calibration refreshes and at most 3,840 compatibility scoring rows (six checkpoints × two contexts × [192 bank + 128 visited rows]) are authorized. Additional training-probe and training-neighbor computations are inference only and must be metered. Cap the entire attempt at 7,200 seconds and stop without automatic retry on timeout or failure. Zero simulator transitions and zero actor, critic and target updates. Output is written only in this new development package; frozen input packages and checkpoint files remain untouched.

Results must show all six checkpoints and both contexts. For a checkpoint/context, call the exploratory cell qualifying only if the combined score changes at least one raw-Q choice, its harmful-switch count does not exceed its improved-switch count, and its mean 32-anchor bank regret is strictly lower than both compatibility-only and strength-matched width on that same checkpoint. A context passes if at least two of three seeds qualify in **each** of the native and original-BCA checkpoint groups; the exploratory signal passes if either context passes. This is a *mechanism screen*, not evidence of improvement in trained policy returns or a fresh test. Record exact changes, failures and counterexamples regardless of outcome; no tuning or candidate selection from these results is permitted as confirmation.
