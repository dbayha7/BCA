**One proposed test:** change only the local objective's aggregate coverage term to a bootstrap-weighted per-row quantile loss, while holding the one-sided labels and all other adaptation settings fixed:

```
r_i = (Q1_i - y_i) / u
rho_0.9(e) = max(0.9*e, -0.1*e)
loss = sum_i w_i * rho_0.9(r_i - eta_i) + 0.005*sum_i w_i*eta_i^2
```

This fits a positive directional uncertainty scale to logged native-target residuals, not a signed mean return correction. The retained width regularizer means eta is a regularized quantile-oriented predictor, not an exact conditional 90th percentile. Separate Bayesian/conformal calibration remains responsible for the global threshold.

**Calibration wording:** alpha=.1 sets the intended native-target miscoverage tolerance to 10%, hence nominal coverage 90% for `y >= Q1-U`. Credibility=.95 concerns the bootstrap posterior probability that the score-distribution risk meets that tolerance; the implementation selects the corresponding posterior crossing order statistic and takes the maximum with the empirical threshold. It is not a 95% coverage target. The sigmoid sharpness parameter 20 is separate from either probability. Observed 116/128=90.625% is only this logged validation sample's coverage. It neither proves 90% population coverage with 95% frequentist confidence nor establishes true-return, selected-action or OOD coverage; adaptive calibration reuse further limits such claims. `certified_numerically` indicates a finite numerical threshold, not empirical validation of those assumptions.
