# BCA and IW-BCA: stage and evidence audit

Audit date: 2026-10-21. Repository: `C:\Users\David\dev\BCA`, HEAD `b007052a2494dc651ac00469fa9e922b287cd1e5`. This audit read existing source and studies; it did not launch training or change the repository. Current working-tree hashes, rather than an older cloud checkout, identify the implementation. The `bca/` mirror is untracked and is not a separate validated version.

The most promising existing policy signal is the **action-support-aware lower-edge experiment with separate treatment of zero support and insufficient calibration mass**, but advancing it is now **blocked on a confirmed probability-law defect**: its claimed exact command ratio omits atoms created by clipping its target noise and actions. Recorded return gains remain descriptive; globally exact-ratio calibration does not. Its gains are exploratory, actor-only, and depend on privileged recording information. Its estimated-weight follow-up lost most of that benefit and failed its declared gain-retention criterion. Native BCA, context-weighted BCA, the lower-edge variants, and the historical weighted-conformal reference must be presented as different methods.

Native BCA measures width at **recorded actions** before multiplying their cloning term. The lower-edge experiments instead evaluate width at the actor action and subtract an actor-vs-recorded width difference from the actor's value objective. These are different interventions.

## Confirmed exploratory command-law defect

The implementation draws `z=clip(.2*N(0,1),-.5,.5)` and `a=clip(actor+z,-1,1)` (`command_band_check.py:261–264`). This places positive target probability on noise-clipping hyperplanes and action boundaries. Its density function instead returns Gaussian density only for strict `abs(a-actor)<.5`, returning negative infinity elsewhere (`80–85`). With a zero actor centre and first action coordinate+.5, the target has clipping mass but the code assigns zero target density. The ratio becomes negative infinity (`130–136`) and threshold lookup maps it to a small floor **without refusal** (`160–168`). With actor first coordinate .8 and action1, the code gives finite density despite target boundary mass absent from continuous behavior. The independent reviewer confirmed this reading.

This is a **scientific contract failure in the exploratory command-ratio branch**, not a failure of native BCA or the core current-law ratio `w(c)`. Finite-precision rounding does not rescue a claim of an exact continuous density ratio. Repair requires an atom-aware dominating measure or a deliberately changed, clearly specified target law, then an independent fixture and coverage retest. No source or saved training run was modified by this audit.

A separate qualification is that A2 conditions on episode random share, whereas A3 estimates observed-state/action odds. Those ratios need not agree pointwise, although they may represent the same marginal target after a correct derivation. This is an unresolved law-definition issue, not by itself proof that an augmented-space ratio is invalid.

## Does IID mean a low penalty?

No such invariant appears in the code. “IID” means the calibration and test laws agree; it does not mean the critic's residual is small. Equal weights leave nonzero, data-dependent widths. Even an exchangeable task may have high TD error and therefore a large penalty. A width can also grow under correct weighting when the target emphasizes high-residual cases; that is expected behavior, not automatically a bug.

Conversely, high penalty is not automatically correct: a width may fail to distinguish harmful from helpful actor changes, the scale network may misrank actions, estimated ratios may emphasize the wrong examples, or a refusal branch may change the dose independently of weighting. Native and historical IW infinity behavior is a reproducible example of the last case.

To distinguish consistent behavior from exceptions, preserve per-seed/per-context records for `(residual, eta, unit, bank weight, query mass, ESS, threshold, width, refusal reason, multiplier, actual action harm)` and inspect the same cases at each stage. Report separate finite coverage, refusal rate, coverage conditional on a finite band, critical-support recall, and false-refusal rate. “Covered or refused” alone can look excellent while most useful actions are refused.

## Smallest next comparison — proposal only, not launched

First complete isolated deterministic fixtures and an independent-observation ratio audit. Reproduce: equal weights; common rescaling; distinct query mass; a high-residual IID case; a shifted law emphasizing low versus high residuals; zero support; finite-but-insufficient mass; clipping at a fixed preregistered cap; and a deterministic actor versus a deliberately specified smoothed actor law. A high IID penalty is a failure only when it violates the stated component invariant or fails a separately stated usefulness criterion.

Only after the law repair and isolated checks, freeze **one** action-support-aware lower-edge rule on **one predeclared data quality**. Use five fresh paired seeds and the existing actor-only frozen-critic budget of **20,000 actor updates in 4,000-step chunks** (`experiments/shift/learners.py:138–139`, `lower_edge.py:25`), not the 100k full actor-critic budget. Minimum arms: (A) matched unweighted lower edge; (B) exact-ratio oracle using the same observable state/action law as the estimator; (C) estimated ratio on that same law; (D) state-independent intervention matched to B's mean magnitude/refusal count per chunk; (E) corresponding magnitude-matched control for C. This is **25 actor-only jobs after passing the component gate**, proposed and not launched. The other quality is a separately preregistered extension; 50 jobs is the complete two-quality matrix, not the smallest next launch. Freeze config, seeds, source hashes and primary contrasts before any run. If component or observability checks fail, stop before training.

The existing random-location controls match the number of no-credit rows. Add a constant intervention matched to actual mean penalty/gradient magnitude: equal counts do not guarantee equal strength. Hold the refusal mapping, calibration rows, critic, actor initialization, minibatches, noise, normalization, evaluation starts and budget fixed within each pair. Keep exact-oracle and estimated-ratio results separate. Use one primary context/quality contrast per claim and report all other cells; do not select checkpoint or fallback by test return.

For native capped cloning, a cheaper diagnostic ablation on saved states should first compare adaptive multipliers against all-one and equal-mean constant multipliers with identical refusal behavior. It answers whether localization adds value before any new full training matrix. Long-horizon Q error and action harm should be measured independently of the one-step calibration label.
