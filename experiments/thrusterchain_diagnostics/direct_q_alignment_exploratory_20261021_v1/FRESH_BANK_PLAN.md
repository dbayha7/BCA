# Small fresh-bank signal confirmation — proposed, not run

The current bank is exploratory. The next bounded question is whether this frozen width provides useful **within-state value-error information** on an independent draw, beyond action distance and simply keeping the original actor. It is not yet a training experiment or a test identifying epistemic uncertainty.

1. Before new labels, freeze the existing 100k actor/critic, 95k reference, exact source hashes, single-row deployment convention, preprocessing, kappa=1 and the already fixed distance coefficient 0.519506430786272. Make no recalibration, architecture change or outcome-based adjustment. A changed predictor/target would require a separate protocol.
2. Use one independent replication of the same designed law: 32 new states, eight per context with the existing 3/3/2 time mixture, and the same frozen 12-candidate construction. Proposed, never generated here: NumPy PCG64(SeedSequence([2026102123, stream])) with stream 1 for states, 2 for actions and 6 for the within-state width permutation. Bind these identifiers in the future freeze before generating data. Save all inputs and scores before revealing Qpi. This is a minimal replication, not a powered general efficacy claim; 32 states do not assure a definitive decision.
3. Compute each candidate's finite-horizon Qpi once using the already validated numerical contract. This gives 384 returns and the same planned 21,696 simulator transitions (loose maximum 38,400), plus any explicitly budgeted fixed replay fixtures. No optimizer steps, training, policy selection or multistep replacement controller. This document authorizes no execution.
4. Keep these fixed controls: raw Q1; Q1−U; the existing matched-distance score; the original actor; constant within-state offset; and a prerecorded within-state permutation of widths. The permutation is an information-destruction control, not an automatically valid exchangeability test or p-value. It requires no extra oracle rollouts. Include the actor only where it satisfies a restricted comparison's eligibility, and report unrestricted actor-baseline results separately.
5. Primary signal endpoint: equal-state mean orientation-invariant Pearson correlation of width differences with signed advantage-error differences, computed with both orientations of every within-state unordered pair. Report every state's contribution and null reasons, the defined-state denominator and undefined-state fraction; do not silently substitute zero for undefined correlations. Compare with the same endpoint for frozen distance and permuted-width controls. Primary decision endpoint: paired equal-state change in action-ranking concordance; selected Qpi versus raw Q is secondary. Use the same 1e−6 near-tie convention for ranking. Report mean return, harm/opportunity loss, signed/absolute/positive error associations and all support/refusal denominators as distinct quantities. Do not optimize a nominal level or coefficient using these labels.
6. Report paired state variation and the previously specified state-stratified interval, preserving all candidate actions together. The context/time strata still contain only 2–3 states; disclose that limitation. Do not count actions/pairs as independent replicates or claim across-training-seed efficacy. Lack of precision or disagreement between endpoints means inconclusive, not a new sweep.
7. Advance only to a separately specified larger study if the prespecified fresh-bank signal and decision endpoints support the proposed direction and the distance/actor controls do not explain the result. If alignment remains near zero, reverses, or merely suppresses all unfamiliar actions, redesign the signal and explicitly align its prediction/target definition before training. Do not use the fresh confirmation bank to tune the redesign; any redesigned method needs its own independent final bank.

This is a draft planning artifact, not an execution freeze. Numerical advancement thresholds, the exact interval decision rule and any multiplicity handling must be fixed before launch and before any fresh labels are inspected. The current plan supplies no power claim and must permit an inconclusive result without extending the run adaptively.

Conditional nominal-level interpretation: with this frozen eta and a single scalar R, a finite quantile change only rescales widths. It can change score strength but not width ranks. A test of a revised per-query threshold, recalibrated Q1/full-return target or learned eta is a distinct future method and must not be substituted into this replication.
