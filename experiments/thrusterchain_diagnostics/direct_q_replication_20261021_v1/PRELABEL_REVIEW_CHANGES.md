# Corrections made before any fresh return labels

Independent source review identified that an initial draft restricted every correlation mean to states where all three signals had defined correlations. The final implementation uses each signal's own defined states for its mean and each pair's common intersection for a paired contrast. Synthetic tests cover a constant-distance state with informative width.

The review also requested explicit reasons for undefined correlations and concordance, and defensive rejection of incomplete or nonfinite continuations even if their accumulated return is finite. Physical position-violation events remain recorded without termination or exclusion. Direct paired selected-return contrasts against distance and shuffled width were added to make the planned comparison explicit.

These changes occurred before preparation and before any fresh Qpi labels. No model, state, candidate, penalty strength, fallback, seed, tolerance or transition budget changed. The frozen source hashes are recorded in prepared/preparation_manifest.json. All 12 pure tests passed before preparation.
