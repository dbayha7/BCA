# Provenance and delivery scope

This folder is a new, bounded, descriptive fresh-state replication. It preserves the original 30-job training study, the failed V1 numerical receipt, the validated V2 diagnostic, and the subsequent exploratory analysis as separate historical records. No learner was trained or refreshed for this replication.

## Evidence trail

- `protocol.json`, `freeze.json`, `PREFLIGHT_REVIEW.md` and `TEST_RECEIPT.json` establish the specification, reviewed source identities, outcome-free preparation and pure tests before fresh return labels.
- `prepared/inputs.npz` contains every physical state, time, regime, indexed candidate, support mass, native width and permutation. `scores.npz` and `bootstrap_plan.npz` save all choices available before the oracle labels. Their hashes and model parameter identities are bound by `preparation_manifest.json`.
- `prepared/engine_identity.json` records the checkpoint and authenticated historical source closure. `reference.json` records the 95k calibration reference. The original model checkpoint SHA256 is `4088278230fc413c509e27e189daa342468cfc4fb6d2479e3e8c29e149dac3d8`.
- `results/raw_results.npz`, candidate and state CSV files retain all indexed cases, including native refusals, unsupported commands, numerical invalidity and physical violation events. No failed or unusable state is replaced.
- The result and bootstrap files, independent post-run review and arithmetic reproduction receipt document analysis. `reproduce_analysis.py` reconstructs saved statistics without model inference or simulation.

The runtime is Zeus Windows, Python 3.10.11, NumPy 2.2.6, SciPy 1.15.3 and JAX 0.6.2, CPU only, one thread, affinity cores 8–11 and IDLE process priority. Runtime metadata is also saved. This experiment uses project-generated ThrusterChain states and the identified historical project checkpoint; no new Farama dataset is downloaded or assumed. Dataset licensing and institutional ownership are not determined here. The user confirmed approval of the device and AI/cloud workflow; that approval has not been independently audited.

## Reproduction limits

The compact evidence archive supports arithmetic reproduction from saved raw records. It includes the eight authenticated source files used in the signal audit under `audit_source_snapshot/`, but not checkpoint binaries or the complete historical runtime/source bundle. Regenerating return labels requires those original local dependencies, whose identities are recorded, and the documented Python environment. The independent post-run checker also authenticates external historical receipts; the portable saved-statistics command is `reproduce_analysis.py`. Rebuilding the complete V5 HTML also requires the separately preserved V4 HTML baseline at the documented sibling path; the finished V5 guide is delivered separately from the compact ZIP. The calibrated reference and actor have different update ages; no inference here attributes weak alignment to that lag. The labels are deterministic conditional numerical returns, not globally certified error bounds or population expectations.

Browser rendering has not been tested in this task. Static HTML integrity and preserved historical content can be checked separately; a static check is not a browser test.
