`global_precommit.py` checks an externally pinned index covering every256 nominal
capture rows of one declared pair before sealing. "Global" here means the whole
pair, rather than allowing outcome collection while its other states/candidates
are still being prepared. It does not require all20 pairs to collect states first.

Each captured row binds the supplied full-state contents, exact100/300 counter,
nonterminal flags, call-evidence identity,14 candidate slots, all250 saved keys
and14 warning entries. Missing rows retain the native terminal evidence and cannot
have candidate banks or scores. Both captures in a block must be chronologically
consistent, and both collectors retain the same reset seed. Fixed native/anchor
slots, aliases, missing support slots, support scores, constant baseline and native
width N/A are preserved. Finite width and fixed-random score entries are required.
All64,000 supplied key pairs and their row/table hashes are checked. No JAX
derivation, reseeding, pool generation, actor query or outcome selection occurs.

The raw reader must return externally hash-bound canonical finite JSON. Typed
snapshot array bytes, including signed zero, are retained without decoding or
inventing native fields. The collector's saved row excludes its subsequently
added in-memory artifact hash; the index uses the saved raw-byte hash explicitly.
Source dependencies are reread before acknowledging the seal. The seal explicitly
sets semantic, execution and scientific acceptance false.

These checks do NOT independently establish native restore-schema completeness,
seed derivation/inventory completeness, normalization/neighbor ordering, training
provenance, native actor actions, candidate reconstruction or warning numerics.
The separately pinned independent review must bind the seal and execution
declaration and accept those semantics, actual runtime/paths, native action/reward/
repeat checks, resources/storage/ownership and supervisor path. A supplied hash or
boolean cannot establish the reviewer's provenance; the outer execution capsule
must independently pin the reviewer, its actual successful exit and its inputs.
The tests use invented review receipts. They authorize no real execution.

`phase_barrier.py` scans the full dependency set at phase entry, then rechecks the
common roots and current panel before and after each injected callback. It uses
fixed host then BCA order,256 nominal rows each, including missing rows without
calling the outcome callback. It saves a unique phase claim and each panel start
before invoking the callback, and saves completion afterward. Process/lease loss,
changed bytes, failed readback, callback failure or reentry poisons the phase;
unresolved starts remain visible. A second instance cannot reuse the same claim.
This is not a restart/recovery protocol or protection against arbitrary Python
code bypassing the declared interface. The actual supervisor must make this the
only path to the accepted driver under an exclusive, durable archive/lease.
