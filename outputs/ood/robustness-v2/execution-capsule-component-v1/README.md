# V2 engineering execution capsule prerequisite

This is a read-only declaration/review binding component. It creates no worker,
model, simulator, resource lock, ledger or archive. It does not accept the actual
runtime or authorize the pending stream amendment. Forty-six synthetic tests
passed with actual exit 0 and no skips. The sources are now closed.

The capsule checks the exact original plan hash, one of the twenty declared
host/environment/training-seed pairs, the full frozen v2 scope caps and unchanged
combined global ceiling. Its only supported phase is engineering. The returned
binding names only the matching engineering scope; collection and outcome
acceptance require a separate integration. Single consumption, process identity,
unchanged declarations and immutable input identities are checked. Reuse, fork,
mutation or failed checks poison further use. This is not a Python sandbox or
an enforcement mechanism against a caller bypassing the required route.

Fourteen asset roles must be externally pinned: original plan, training
acceptance, both checkpoints, prepared data, support bank, stream acceptance,
ancestor binding, runtime graph, native schema, storage acceptance, supervisor
acceptance, entrypoint and interpreter. Each file is an absolute unaliased regular
file with independently supplied SHA256 and device/inode/size/mtime/ctime identity.
Initial hashes are streamed with a 2GiB bound; JSON declarations/reviews use the
closed bounded parser. Later checks retain exact identities without repeatedly
hashing large files. Hardlinks, symlinks and altered files are refused. A reviewer
may use the same interpreter only with the identical explicit pin.

The new run root must be absent under an existing bound parent; extension ledger,
archive and dispatch must be distinct direct children. Inputs and review files
cannot alias these outputs, the shared lock or original ledger. Existing output
paths are retained and refused. The declared original ledger is checked only by
its independently bound file identity, absence of sidecars and combined reserved
totals; no SQLite connection or full scan is made. The closed AncestorGuard must
still check its read-only header/head/cached totals at actual execution.

Worker and reviewer commands must name exact pinned interpreters/entrypoints,
isolated Python mode and the same declaration. The engineering environment is
explicit CPU-only with no extra inherited override fields. The actual supervisor
must use that exact environment and separately accept any required native-library
environment rather than silently merge it. This component does not start either
command or prove compatibility of this minimal environment with the real runtime.

The independently supplied reviewer report and separate actual process receipt
must bind the exact declaration, asset hashes, reviewer source, command and report
bytes. All ten fixed semantic gates must be true. Missing/held gates, stale report,
null/nonzero/boolean exits, timeouts, interruptions, same-process review and invalid
timestamps are refused. Gates cover training, checkpoint/data/support, fresh
streams, runtime graph, native factory/import/wrapper paths, restore schema,
action bounds, original resources/shared lease, storage and supervisor route.

These relationships do not certify the origin or truth of a review. Trusted
observer/reviewer pins must themselves be independently accepted outside this
component. The actual complete dependency graph, import paths, native field
coverage, wrapper/decorator bindings, checkpoint semantics, shared-lock path,
device storage behavior and only-route supervisor are still pending. Synthetic
receipts contain invented passing gates; they authorize no real execution.

Tests use temporary synthetic files, fake checkpoint/runtime/ancestor bytes,
invented review/exit receipts, and a byte-exact temporary copy of the frozen
scientific plan. They do not import scientific modules or acquire even a synthetic
flock. The ancestor file is not SQLite. No real JAX key, candidate pool or model
was generated. The held fresh-stream gate is explicitly tested to refuse.

The first 36-test development pass exited 0. Source review then tightened review
file alias refusal against mutable lock/ancestor paths, retained explicit same-
interpreter reuse and added ten refusal/identity cases. The final 46-test run
exited 0. No missing-module red was captured; no prior closed suite or audit reran.
