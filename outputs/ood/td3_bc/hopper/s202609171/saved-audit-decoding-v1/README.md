# Saved-value decoding and bounded real integration

`saved_values.py` independently decodes the frozen artifact JSON, simulator state JSON and uncompressed NPZ payloads. It imports no collector, model or simulator code. It does not use pickle or `numpy.load`. Before allocating arrays it checks explicit field schemas, input/expanded/header/shape/depth/node bounds, exact lengths, canonical numeric dtypes and hex, duplicate members/keys, finite values and hashes. It preserves signed zero, byte order, inactive fields, artifact tuple markers and scalar extraction. Simulator JSON serializes tuples as lists; this decoder preserves that loss of type information rather than inventing tuple identity.

Twenty synthetic tests passed in the existing Python3.10/NumPy environment with actual exit0 and no skips. They cover real `np.savez` layouts, unicode state scalars, Fortran arrays, malformed headers, duplicate/path members, object and structured dtypes, corrupt lengths/CRC/hashes, oversized declarations, nonfinite values and invalid boolean bytes. The expected initial missing-module failure is retained in `monitor_20260928T160054Z/saved_values_red*`; the successful test receipts are `saved_values_v1*`. Earlier closed component sources/tests were preserved and not rerun.
